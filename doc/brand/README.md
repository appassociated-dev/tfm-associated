## Qué es este directorio

Aquí vive la definición de marca de Associated: desde el propósito y los valores hasta los tokens de diseño que se aplican directamente en el código del frontend. Son dos documentos complementarios - uno estratégico y otro técnico - que garantizan coherencia entre lo que la marca dice y lo que el producto muestra.

## Resumen de identidad

### Valores

| Valor                                  | Criterio de decisión                                                      |
| :------------------------------------- | :------------------------------------------------------------------------ |
| Cercanía al dominio                    | Hablamos el idioma de las colectividades, no traducimos jerga corporativa |
| Respeto por el tiempo del voluntario   | Cada clic innecesario es tiempo robado a la comunidad                     |
| Accesibilidad sin condiciones          | Ninguna colectividad fuera por presupuesto ni por conocimientos técnicos  |
| Transparencia como estándar            | Rendición de cuentas por diseño, precios claros, sin letra pequeña        |
| Continuidad por encima de las personas | La información sobrevive al relevo de junta                               |

### Personalidad

Funcional (resuelve, no decora) · Directa (frases cortas, vocabulario llano) · Fiable (solidez sin proclamarla) · Natural (tuteo sin confianzas impostadas) · Discreta (protagonista es la colectividad, no la herramienta).

### Paleta

| Token         |    Hex    | Uso                            |
| :------------ | :-------: | :----------------------------- |
| Midnight blue | `#27343E` | Color primario, fondos oscuros |
| Slate teal    | `#5B7682` | Superficies activas, acentos   |
| Silver sage   | `#7A939E` | Bordes, texto secundario       |
| Cloud gray    | `#8CA1AA` | Fondos secundarios             |
| Pearl white   | `#F5F5F0` | Fondo principal                |

### Tipografía

**Inter** como familia única para interfaz y comunicación. Pesos 400 (cuerpo), 500 (énfasis), 600 (títulos). Sin serifas, sin familias secundarias.

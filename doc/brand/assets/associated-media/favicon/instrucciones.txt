1. Download your favicon package.
2. Extract this package in <your app>/public/.
3. In <your app>/public/index.html, remove the existing link markups (they have have attributes rel="icon", rel="apple-touch-icon" and rel="manifest").
4. Insert the following code in the head section of <your app>/public/index.html:
    <link rel="icon" type="image/png" href="%PUBLIC_URL%/favicon-96x96.png" sizes="96x96" />
    <link rel="icon" type="image/svg+xml" href="%PUBLIC_URL%/favicon.svg" />
    <link rel="shortcut icon" href="%PUBLIC_URL%/favicon.ico" />
    <link rel="apple-touch-icon" sizes="180x180" href="%PUBLIC_URL%/apple-touch-icon.png" />
    <meta name="apple-mobile-web-app-title" content="MyWebSite" />
    <link rel="manifest" href="%PUBLIC_URL%/site.webmanifest" />

5. Start your application:
    npm start

6. Make sure your favicon is properly setup:
    npx realfavicon check 3000
